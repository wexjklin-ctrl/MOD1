# Порт аддона «RZ Auto» (Bedrock v1.33) → Fabric-мод для Minecraft Java

Цель: перенести ВСЕ фишки аддона, модели, скорости/баланс и свет фар (с поддержкой шейдеров).
Исходник: `rz_авто.zip` (BP + RP). Этот пакет — выжимка данных и конвертеры, проверенные на исходнике.

## 0. Целевая платформа (проверить на ПК перед стартом!)
- На скриншоте пользователя: `fabric-loader-0.20.1-26.3` → Minecraft **26.3**, Fabric Loader **0.20.1**.
- По найденным публичным данным для 26.3: Java **25**, Fabric API **0.165.0+26.3**, маппинги Mojang (Yarn нет).
- API рендера/сущностей в 26.x сильно отличается от 1.21.x — сверяться с исходниками Minecraft/Fabric API на ПК,
  а не с памятью. Мод ставится и на сервер, и на клиенты (клиентам нужны модели/звуки/HUD).

## 1. Что в пакете
| Файл | Что это |
|---|---|
| `data/vehicles.json` | 307 машин: id, геометрия, текстура, места (seat offsets), коллизия, step-height, HP, клиентские анимации/Molang-скрипты, профиль баланса |
| `data/balance.json` | Все таблицы баланса: топливо, поломки, регенерация, разгон, макс. скорость, 7-я передача + константы профилей |
| `data/id_map.json` | Bedrock id → Java id (`rz_auto:<ns>_<name>`), прочие предметы/блок |
| `data/recipes.json` | 309 рецептов (307 машин + шестерня + права), станция `rz_auto:bench` |
| `tools/extract_data.py` | Перегенерация vehicles.json/balance.json из аддона |
| `tools/make_idmap.py` | Перегенерация id_map/recipes |
| `tools/convert_textures.py` | Bedrock PBR (color+MER) → Java labPBR (`_s`) + маска свечения `_e` |

Единицы скорости: **1 ед. = 1 блок/тик = 72 км/ч** (так считает спидометр оригинала). `top_speed`, `gear7.speed`
в этих единицах. Значения `movement_bedrock` в entity-файлах УСТАРЕЛИ — источник истины это `top_speed` из balance.json
(см. комментарий в `vehicle_profiles.js`, v1.22.5).

## 2. Архитектура мода
- Один мод `rz_auto`, данные-ориентированный: при инициализации читает `vehicles.json` и регистрирует 307 `EntityType`
  (класс `VehicleEntity`, один на все) + 307 предметов-«ключей» (аналог spawn egg, ставит машину), id по `id_map.json`.
  Отдельный тип на вариант нужен, чтобы восстановление машин на карте шло по старому типу один-в-один.
- Профиль машины (скорость/топливо/…) резолвится по `family_prefix` (самый специфичный префикс первым — как в JS).
- Серверная физика в `tick()` сущности; ввод водителя — от клиента (кастомный пакет, либо вход пассажира-водителя из API 26.x).

## 4. Модели
Bedrock geo 1.12.0, 21 файл, до 545 кубов (GLS), вложенные кости с pivot и поворотами кубов.
Рекомендация: runtime-загрузчик `.geo.json` → дерево `ModelPart` (кость = часть, куб с собственным поворотом = дочерняя часть
с pivot). Экспорт в vanilla block-model JSON не подходит (поворот элементов только 22.5° по одной оси — модели испортятся).
Размеры текстур по geo: 128/256/512. Анимации — переписать Molang-формулы на Java (небольшие, см. `client_scripts`).

## 5. Свет фар и шейдеры (главная просьба)
В Bedrock фары светятся через MER (G = emissive). В MER у машин G очень слабый (≤25) и бинарный — это маска фар/подсветок.
Конвертер даёт:
1. `<tex>_s.png` — **labPBR specular**: R = 255 − roughness(B), G = F0 (металл → 255, диэлектрик ≈ 12), B = 0, **A = emissive** (254 где была маска, 255 где нет).
   Положить рядом с цветной текстурой в `assets/rz_auto/textures/entity/` — Iris/Optifine-шейдеры с labPBR подхватят без кода мода.
   Параметр `--emissive-boost` (0..1) регулирует яркость свечения.
2. `<tex>_e.png` — маска свечения для **ванильного режима без шейдеров**: второй слой рендера (fullbright, как у глаз паука) только по маске.
3. Рекомендации для универсальности: рендерить кузов стандартным entity render type (чтобы шейдеры применяли свои entity-программы
   и PBR); не делать собственных нестандартных RenderType для основного слоя. Не все шилдпаки применяют PBR к сущностям мода — проверить на 2–3 популярных (Complementary, BSL, Photon…).
4. Опционально: динамический свет фар (невидимые light-блоки впереди машины или совместимость с LambDynamicLights).
Метка «headlights fixed» в описании аддона — для Corvette C2, Centenario, P1, 458, LaFerrari, F40: проверить их фары первыми.

## 6. Известные проблемы данных
- `bmw:m3whitered`: цветная текстура 3092×3092, а MER 256×256 и geo 256 — текстуру нужно ужать до 256×256 (конвертер ресайзит MER «в лоб»).
- 137 из 307 машин — Jeep YJ на одной геометрии `yjtest` (общий MER `ambient_jeep`).
- 306 из 307 текстур имеют ненулевой emissive → проверить, что светятся только фары/подсветки, а не вся «ambient»-область.
- `BP/items/111*` — служебные файлы-дубли, в порт не нужны.

## 7. Восстановление предметов и машин на карте (для Claude на ПК)
Конвертеры мира (Chunker и пр.) переносят блоки, но НЕ кастомные сущности/предметы:
1. Блок `carworkshop:bench` → `rz_auto:bench`; `minecraft:cardinal_direction` south/east/west/north → facing (модель повёрнута 0/90/−90/180).
2. Машины (entities в LevelDB мира): вытащить тип, позицию, поворот и dynamic properties, создать `rz_auto:*` по `id_map.json`.
   Свойства для переноса: `owner`, `lock_state`/`locked`, `fuel_blocks`, `mileage_blocks`, `mileage_checked_index`, `broken_down`, `gear`, `gear_mode`, `gear7_left`, `gear7_locked`,
   `speed_percent`, `turn_strength`, настройки руля/камеры/звука/спидометра (`wheel_*`, `gta_steering`, `free_camera*`, `racing_camera*`, `rz_sound_*`, `speedo_*`), `susp_on`, `seat_fix`, `drift_mode`.
   Временные `gv_*` и `rz:steer` НЕ переносить.
3. Предметы в инвентарях/сундуках: `<ns>:<name>_spawn_egg` → предмет `rz_auto:<ns>_<name>`; `carworkshop:driver_license|gear`, `rz:vehicle_remote` — по таблице `other_items`.
4. Для каждой потерянной машины сначала сверяться с `id_map.json`, а не угадывать id.

## 8. Порядок работ
1. Gradle-проект Fabric 26.3 (шаблон на ПК), пустая загрузка мода.
2. Загрузчик geo + рендер одной машины (f40) + колёса/руль. Затем все модели.
3. Регистрация 307 типов из JSON, предметы, лэнг (`RP/texts/ru_RU.lang`, `en_US.lang` → `lang/*.json`), верстак, рецепты.
4. Физика + баланс + топливо + износ + права/замок/владелец.
5. Меню, передачи, режим руля, камера, HUD-спидометр.
6. Звуки, частицы, оборудование (тент/мигалки/подвеска).
7. Свет/шейдеры: `_s`/`_e` текстуры, проверка в Iris.
8. Миграция мира (раздел 7).
