# Wheel / ground model — `applyPhysicsWheelForces(currentTick)` (main.js L1508-1924, READ line by line)

Called every tick from the physics `step` hook (after `runtime.step()`), so everything here corrects the body **after** the engine moved it. Wheels are not rigid bodies: each wheel attachment (`physicsWheelAttachments`, fields `assembly, entity, localLocation, rollingAxis, dimension, groundOffset, suspOffset…`) is only a probe. The car body is a normal body that this function holds up, tilts, springs and puts to sleep.

## Per car (grouped by assembly), in order
1. Skip if held by gravity gauntlet (resets parking state) or `session.streamingMotion` (chunk unloaded).
2. `airplane` flag from `vehicleSystems(session)`; `drive` = wheel throttle (`wheelThrottleForAssembly`) or, for planes, 1 if engine on. `rest` = per-assembly state object in `physicsWheelRestState` (all fields below live there).
3. `syncCarBottomCollision` (collision-shape switch) unless lying and idle. `rzFlipStep` (RZ): handles a fallen car; if it consumes the tick → `continue`.
4. `commanded` = throttle, or rolling (speed > 0.08; 0.005 if low grip; `SUSP.HIT_IGNORE` for parked pose), wing drive, propeller drive, towed by rope. Commanded clears parking state.
5. **Mass/COM rebuild** when block list/count, wheel count or plane flag changed: COM = centre of wheel mounts (y−0.5) or, for planes / `RZW.ON`, the real mass centre `aircraftStructureCenterOfMass`; `body.setCenterOfMass`; resets lying/tip/park state.
6. Lying state ("упала"): one wheel + no throttle → `rzLie` immediately (`ONE_WHEEL_LIE`); lying cars are only put to sleep by `rzLyingStep`; they stand up again if ≥3 wheels and up-vector y > 0.9, or throttle with ≥3 wheels.
7. Parked pose: if not commanded and parked supports still have the same terrain top (±0.001) → `restoreParkedWheelPose` and skip the whole tick (cheap path). Otherwise unpark + wake. If `settled && sleeping && !commanded` → skip.
8. `alignTowedCar`; zero angular velocity (unless airborne, so flips can happen).
9. `axle` = horizontal unit vector of `wheels[0].rollingAxis` in world (= car forward axis); `speed` along it; `travelSign` = sign of drive, else of speed (>0.08).
10. **Probes**: stationary cars freeze probe points (`rest.probes`) so a wheel on a block edge does not flicker.
11. **Ground search per wheel**: scan blocks from `round(y)` down 4; `wheelTerrainTop(block,x,z)` gives top surface (undefined = no collision). `tireSupport = tireR - 0.5`; `supportY = top + tireSupport - wheel.localLocation.y + ride` (`ride` = `rzRideOf` clearance slider+`SUSP.RIDE`). Step lookahead when moving: three insets (0, .75, 1.5 blocks toward car centre), lookahead `clamp(0.45+0.9·tireR, 0.8, 1.7)`; a higher block ≤ `maxStep` with air above raises `targetY`/`wheelTop`. `maxStep = min(2.05, max(tireR, wheelCentreHeightAboveGround)+SUSP.STEP)`. Each wheel pushes a `supports[]` entry `{wheel,height,sideHeight,terrain,ride}`; no ground → `suspensionOffset=0`.
12. Wheel *mounts without a tire* act as virtual supports at ground−0.25 (chassis drags).
13. Airplane: supports kept only if within `AIRPLANE_GROUND_REACH`; `targetY` from max of `height − (pointY − originY)`; no supports → plane free flight, `continue`.
14. **Air check** (`SUSP.ON`): airborne if every wheel is > `SUSP.AIR_GAP` above support; `rzAirTrack` returns 0 grounded / 1 / other airborne states; airborne cars `continue` (wheels hang `suspOffset=-0.2`). Quiet airborne body for 20 ticks → `rzLie`.
15. **Pitch/roll fit (≥2 supports)**: least-squares line of support height vs distance along the axle axis → `slope`; `incline = asin(slope)` in degrees minus `rzTipBias` (cargo outside wheelbase), clamped ±50°; same laterally (±40°). Optional hull probes (`SUSP.HULL`) add virtual supports so nose/belly lift over steps. Rotation eased 20 % per tick toward target (`body.setRotation`), only if angleError > 0.08. `targetY` = max over supports of required body origin height.
16. **Vertical resolve**: `heightError = targetY − origin.y`; supported if ≥ −0.35 (plane: −reach). RZ path (`SUSP.ON`): `suspSpring` → `snap` teleports up, then velocity set to `{h.x, spring.vy, h.z}` with `h = rzGroundVel(v, axle, grip, braking)` (lateral damping/braking) and an anti-gravity force `mass·11` (cancels g=−11). Legacy path: teleport by `correction`, zero vertical velocity, support force `mass·max(0, 11−airplaneLift)` (plane applies at `airplaneSupport` point).
17. `touching` = supports within 0.38 (plane: reach) of wheel; wheel visuals `suspOffset = suspOffset(height − pointY)`; `rest.surfaceGrip = wheelContactGrip(...)` (<1 ⇒ slippery ⇒ treated as commanded); `rest.groundTypeIds` feeds RZ surface speed caps (`SURF_*`).
18. Planes: wheel brake velocity via `stoppedAirplaneGroundVelocity` (RZ rig brakes only at throttle 0 and <6 m/s).
19. **Tipping** (step 114): `balanced` = COM inside bounding box of ≥3 contact points. `tipping` if not airplane, not balanced, has contacts, `TIP_K>0` and (≤2 wheels, or no throttle and (≤3 wheels or some wheel unsupported)). Applies gravity force at COM + angular velocity increment `TIP_K·11·lever/(lever²+1.5)·0.05` about the support pivot; single-wheel case also rolls sideways. After `TIP_TICKS` (40) or 5 still ticks → `rzLie` (released & slept).
20. **Parking/sleep**: `holdParkedWheelPosition`; vertical jitter damping (`SLEEP_K`); stable-pose counter `parkTicks` → `parkedPose` (+`restoreParkedWheelPose`, `suspReset`); `quiet` counter → `body.sleep()` after max(6, ceil(20/SLEEP_K)) ticks (plane 20).
21. Armchair throttle without a steering-control wheel: `change = clamp((throttle·3.2 − speed)·0.2, ±0.2)·√grip` added along axle direction (RZ gate `rzCanDrive`). Note 3.2 m/s base speed; real acceleration for RZ cars is in `stepRzDrive`.
Errors are swallowed; a warning is logged every 100 ticks only.

## Rewrite hints
Everything is `body.setVelocity/teleport/setRotation` + one upward force; no wheel friction solver. A reimplementation needs: terrain-top query, per-wheel support heights, plane fit for pitch/roll, spring, sleep/park state machine, tip/lie state machine. Neighbours still unread: `wheelTractionVelocity` (L1925), `applyPhysicsWheelTraction`, `rzGroundVel` (rz_susp L57), `syncParkedWheelBodies`.
