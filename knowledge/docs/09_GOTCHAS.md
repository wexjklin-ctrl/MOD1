# Gotchas
- **Bundles**: `main.js`/`physics.js` are generated JS; function line numbers in annotated headers are *original* lines (header adds N lines).
- **Mojibake** in some comments (double-encoded UTF-8); main.js L21802 is a single 132 KB comment line. physics.js L12634-12641 hold huge generated collision tables (one line each, up to ~155 KB). Use Python (not `cut -c`/`head -c`, which count bytes) or the shell tools may break on invalid UTF-8.
- **Missing generators**: files claim to be generated by `tools/gen_*.py` referencing `RZ_Physics_BP/...`; those are not in the addon.
- **Dead files** listed in 01; do not "fix" them.
- **Toggle constants** (`STEER_V2`, `TRACK_TURN_V2`, `INVERT_INPUT`…) encode past bug-fixes; changing them flips controls.
- Bedrock watchdog: avoid serializing many big structures in one tick; use `system.runJob`/spreading as the author does.
- `main.js` contains both `system7` and plain `system` usage (later patches).
- Regex-derived tables (`scriptevents.md`, `dynamic_properties.md`) are heuristic.
