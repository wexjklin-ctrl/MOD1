## 1. Настройки SUSP (rz_susp.js L9-35)
Хранятся в `world.dynamicProperty "rzlite:susp"` (JSON всего объекта, при загрузке перезаписываются только числовые ключи). Команды `/scriptevent rzlite:susp`: `on|off`, `flip on|off`, `calm on|off`, `set <ИМЯ> <число>`.
Значения по умолчанию: ON 1, K 110, C 15, UP 0.45, VMAX 9, OFF_UP 0.25, OFF_DOWN -0.35, AIR_GAP 0.6, FLIP_ON 1, IMPACT 9, KICK 0.5, AIR_TICKS 4, FLIP_ENTER 0.45, FLIP_EXIT 0.78, FLIP_SLEEP 30, CALM 1, HIT_IGNORE 1.2, SLIDE_DAMP 0.5, LATERAL 0.6, RIDE 0, STEP 0.3, HULL 1, TIP 1, TIP_K 12, TIP_MAX 22. Подробные смыслы - комментарии в исходнике (повторять не буду). Часть констант (`AIR_GAP`, `HIT_IGNORE`, `STEP`, `HULL`) потребляется в `applyPhysicsWheelForces` (04b), не в этом файле.

## 2. Функции (все чистые скаляры, без обхода блоков в тике кроме кэша hull)
Все вызовы идут из `applyPhysicsWheelForces` (`main.js` L1508-1924) на каждое тело; состояние хранится в объекте `rest` (на сессию/колёсный набор).

- **`suspSpring(rest, err, target)`** (L40; вызов L1773): пружина кузова. `err = высота опоры - высота кузова`. Опережение по скорости опоры `vt = clamp((target - prev)*20, ±VMAX)` только если скачок опоры ≤0.3. `err` свыше `UP` (0.45) отрезается и возвращается как `snap` (мгновенный подъём). `vy += (K*err - C*(vy - vt))*0.05` (шаг 1/20 с), зажим `±VMAX`. Состояние `rest.suspVy`, `rest.suspPrev`.
- **`suspOffset(v)`**: визуальный ход колеса: зажим `OFF_DOWN..OFF_UP`, квантование 1/40.
- **`suspReset(rest)`**: обнуляет `suspVy/suspPrev`.
- **`rzGroundVel(vel, axle, grip, braking)`** (L57; вызов L1777): при `CALM` гасит боковую скорость на долю `min(1, LATERAL*grip)`; при торможении и `grip>=1` скорость умножается на `0.92` (или `SLIDE_DAMP=0.5` при скорости <2.5), при `<0.04` обнуляется. Возвращает {x,z}.
- **`rzFlipStep(body, rest, session)`** (L77; вызов L1536, только если не самолёт и `SUSP.FLIP_ON`): `upY` = Y-компонента локальной «вверх». Лежачее состояние `rest.flipped` входит при `upY < FLIP_ENTER (0.45)`, выходит при `upY > FLIP_EXIT (0.78)` и `lin<1`, `ang<0.8` (обнуляет угловую, `suspReset`). Пока `flipped`: `session.rzFlipped = true`, парковка сбрасывается, возвращает `true` (вызывающий пропускает колёсную физику). Тишина (`lin<0.25 && ang<0.3`) `FLIP_SLEEP=30` тиков -> обнуление скоростей и `body.sleep()`. Спящее тело не трогается.
- **`rzLie(body, rest, session)`** (L111; вызовы L1562, L1703, L1857): переводит в режим «лежит» (`rest.lying = true`), сбрасывает парковку/зонды/воздух/`session.rzAirborne`, `suspReset`.
  - L1562: машина с одним колесом без газа (`DRIVE.ONE_WHEEL_LIE=1`, `wheels.length===1`, `|drive|<=0.01`), также обнуляется `wheels[0].suspOffset`.
  - L1703: `wheels.length <= 2 || up.y < 0.9`.
  - L1857: условие не читал в этой сессии (только индексировано; см. 04b).
- **`rzLyingStep(body, rest, calmTicks, maxTicks, topple)`** (L118; вызов L1570 с `LIE_CALM=6`, `max(30, LIE_CALM*6)`, `topple = wheels.length<=1 ? wheels[0].localLocation : false`): пока спит - true. Шаг 118: если `topple` и `lyingTicks<=40`, `lin<3`, `ang<1.5` и наклон `0.2<uy<0.995`, угловая скорость подталкивается (`0.2/dl`) в сторону падения (от колеса к центру масс; без колеса по наклону верха). Иначе, при `lin<3 && ang<4`, скорости умножаются на `0.55` (при `lin<1`) или `0.8`, подпрыгивание вверх `*0.4`. Счётчик тишины `lin<0.6 && ang<1.0`; при `lyingQuiet >= calmTicks` или `lyingTicks >= maxTicks && lin<2` - обнулить скорости, `body.sleep()`.
- **`rzAirTrack(body, rest, session, airborne, forward)`** (L165; вызов L1695): в воздухе считает `airTicks`, запоминает `airVy`, `session.rzAirborne = airTicks>=2`, возвращает 1. На земле: если `airTicks==0` -> 0; иначе `suspReset`, `impact = -airVy`; при `FLIP_ON && airTicks>=AIR_TICKS(4) && impact>IMPACT(9)` добавляет угловую скорость `mag = clamp(2.5+(impact-9)*0.5, 2.5, 7)` вокруг горизонтальной оси поперёк движения (направление по скорости при `>1.5 м/с`, иначе `forward`), ставит `rest.flipped = true`, `session.rzFlipped = true`, возвращает 2.
- **`rzRideOf(session, tick)` / `rzRideRecalc`** (L191/196; вызов L1608 для не-самолёта): просвет колёс = `clamp(SUSP.RIDE + среднее wheelRide по колёсным блокам с hasWheel, -0.2, 0.3)`; пересчёт раз в 100 тиков; 0 при `SUSP.ON=0`.
- **`rzTipBias(rest, body, supports, axis)`** (L207; вызов L1741: `!airplane && SUSP.ON`): `comD` = проекция локального центра масс (`rest.com`) на ось; `lo/hi` = крайние колёса, реально стоящие (`p.y - height - ride <= 0.3`, не `virtual`); вынос за базу с мёртвой зоной 0.15; `target = clamp(eff*TIP_K(12), ±TIP_MAX(22))` градусов; сглаживание `tip += (target-tip)*0.15`; результат ≈0 при `|tip|<0.05`. Вычитается из наклона по склону вызывающим.
- **`rzHullProbes(assembly, rest, axis, sign, tick)`** (L235; вызов L1723): кэш `rest.hull` (по `blocks`, длине, оси, пересчёт раз в 100 тиков; сбрасывается в L1550 при смене `rest.com`). `hullEdge`: исключает колёса (`visualEntityTypeId==="create_physics:physics_wheel"`), `collidable===false`, `collisionShape==="none"`; нижний край блока = `l.y + min(collisionShape.min.y) - 0.5` (или `-0.5`); берутся 3 боковых столбца (крайние и средний), в каждом до 3 самых передних нижних кромок, каждая следующая ниже предыдущей (порог 0.05); точка на `0.5+0.12` впереди грани. Возвращает локальные точки для щупа ступеньки (корпус приподнимает нос, не застревает днищем).

## 3. Гусеничная лента (track_belt.js)
Колёса trackwork:* остаются колёсами CM (`create_physics:physics_wheel`), поверх них отдельная сущность `create_physics:track_belt` (тег `rz_track_belt`), едет всадником на коллекторе конструкции (`assembly.rzAttachExtra(entity)`; при удалении `rzDetachExtra`).
- **`analyzeTrackBelts(blocks)`**: берёт блоки-колёса с `visualProperties["create_physics:wheel_variant"]` из {4:"w", 5:"a", 6:"b", 7:"c"}; направление качения: ось X если `|sin(yaw)|>|cos(yaw)|`, иначе Z; группа по (ось, боковая координата `lat`); `items{y,t,code}`; нужно ≥2 колёс. Ищет готовую раскладку по ключу (`keyOf`: отсортированные `y.t.code` относительно минимумов) в `TRACK_KEYS`; если нет - зеркальный вариант; если нет и ≤14 колёс - пробует убрать 1-2 лишних (шаг 108). Возвращает `{layout, ox, oy, oz, dx, dz, key}`; без раскладки лента не рисуется.
- **`updateSession`** раз в тик (`system.runInterval(...,1)` по всем сессиям): при смене `assembly.blocks` пересоздаёт список лент (старые по ключу переиспользуются). Спавнит сущность в `localPointToWorld(visualAnchor)`, ставит свойства `track_layout`, `local_pitch/roll=0`, `local_yaw = atan2(-dx,-dz)+yawOffset`, `local_x/y/z = (ox,oy,oz) + offX/Y/Z - anchor`. Прикрепляет и вызывает `assembly.syncVisuals(true)`.
- Скорость ленты: смещение точки борта (`ox, oy+0.5, oz`) между тиками, проекция на направление ленты, `*20*16` (px/с), сглаживание `0.5`, в свойство `create_physics:track_speed` (зажим ±4000, шаг 0.5). Спящее тело -> 0. Клиент сдвигает UV лентой.
- Настройки в `world.dynamicProperty "rzlite:track_cfg"`; `/scriptevent rzlite:track` `flip|yaw <deg>|inv|off <x> <y> <z>|off_reset|off_on|off_off`. После любой команды все ленты пересоздаются.
- `cleanOrphans` раз в 100 тиков удаляет сущности `track_belt`, не привязанные к живой записи (по overworld/nether/the_end).
- Связь с физикой гусениц: сама лента чисто визуальная; поведение гусениц (поворот на месте, `TRK_*`) - в `rz_drive.js`/04c.

## 4. HUD (rz_hud.js, rzHud в rz_drive.js)
Пакет в канал title: строка `rzhud:` + mode(c/a/b) + kmh(3) + alt(4) + scale(3) + fuel%(3) + heat%(3) + thr%(3) + gear(1) + 14 флагов 'y/n' + шкалы 30/10/10/10. Цифры кодируются буквами `a..j`, пустой разряд `x`. Порядок флагов: hasFuel, hasTemp, noEngine, fuelEmpty, fuelLow, overheat, hot, limit, thin, stallAero, stallCeil, brake, airborne, shallow. **Должен совпадать с `make_ui.py`/`ui/rz_hud.json` ресурс-пака** (не читал). Раз в 4 тика интервал шлёт `rzoff`, если обновлений не было >8 тиков.
`rzHud(player, session, info, st, plane, speed, throttle)`: для самолёта скорость = `rig.airspeed`, предел = `rig.vcap*3.6`, `scale = clamp(ceil(max(vmax,kmh)/10)*10, 40, 999)`, тяга = `rig.thr`; для машины `|st.load|`. Передача: `gear = "A"` для самолёта; для машины `R` (тяга>0.05, `wheelAcceleration<0`, скорость<0.5), `D`, `N`. Флаги: `limit = rig.capped`, `thin = rig.air<0.5`, `stallAero = rig.aoa>20 && airspeed>6`, `stallCeil = rig.air<=0.12`, `overheat heat>0.66`, `hot 0.45<heat<=0.66`, `fuelLow fr<0.2`. `brake/airborne/shallow` всегда `false` (не заполняются). Текстовый `hud()` (actionbar с л.с., КПД, температурой, радиаторами, топливом, паром) используется только при осмотре блока (`rzInteract`).

## 5. Заправка и осмотр (rzInteract, rz_drive.js L566)
Вызов из `main.js` L19471-19483: ПКМ по блоку конструкции, если в руке `phys:fuel_bucket` или тип блока подходит под `^(tfmg:|cdg:|phys:(shaft|radiator|fuel_tank|blaze_burner|fluid_tank|steam_engine))`; `event.cancel = true`, антидребезг 5 тиков по ключу `игрок|rz_drive|assembly.id`, действие через `system.run`.
Логика: без информации о двигателе и с канистрой - сообщение; канистра (`FUEL_ENABLED`): ёмкость `capacity(info)`, влезает только целая `BUCKET_L=20`, `r.f += 20`, расход предмета (креатив не тратит; ведро возвращается как `minecraft:bucket`); горелка `phys:blaze_burner` + лава (`BURN_LAVA 20000`) / угольный блок (`BURN_COAL 16000`), предел `BURN_MAX 60000`; бак `phys:fluid_tank` + ведро воды (`+20 л`, ёмкость = баки над горелками * `TANK_L 60`); иначе осмотр: `hud()` если `info.basePower>0`, иначе сообщение «двигатель не соединён». Запасы в хранилище `rec(sid(session))` (`r.f` топливо, `r.b` горение, `r.w` вода), сохранение `saveStore()`.
`/scriptevent rzlite:drive`: `report` (конструкции в радиусе 48), `set <КЛЮЧ> <число>` (ключи DRIVE и STEAM), `fill`.

## 6. Дополнение к 04d: актуальные DRIVE-флаги (rz_drive.js L41-66)
