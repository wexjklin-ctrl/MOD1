## Обновление 4: РЕШЕНИЕ «мод целиком на клиентах» + правила экономии сервера (приоритет №1)
Узкое место — сервер. Поэтому мод ставится и на сервер, и на клиентов (не только ресурспак). Сервер считает только то, что обязано быть авторитетным.
Пакет `com.rzauto.perf` (проверен `tools/SelfTestPerf.java`, оценка `tools/Bench.java`) — используй его, не переписывай:
1. **Сервер**: физика только у машин из `ActiveSet` (едущие и выкатывающиеся). Припаркованная пустая машина НЕ тикает вообще (`Idle.canSleep`),
   будить при посадке/ударе. Выбег пустой — `Idle.coast`, без полной физики. Никаких тиков по всем 307 типам и по всем сущностям.
2. **Сеть**: `NetSync.poll` — состояние раз в 2 тика (деградирует до 6), стоя — раз в 5 с, резкие изменения сразу; пакет = 4 short (`Quantize`), 8 байт вместо 32.
   Клиент интерполирует и предсказывает по скорости/рулю сам.
3. **Клиент** (не сервер!): рендер, поворот колёс (`Wheel.steerVisual`), частицы пыли/дыма, звук двигателя, HUD спидометра (`Speedo.text` считать на клиенте
   по скорости из пакета), камера, свет фар. Сервер этого не знает и не шлёт.
4. **Периодика** (`DriveGate`, износ, пересадка `Seating`, топливо): раз в `Governor.logicInterval()` (5 тиков), фазу сдвигать `Throttle.due(tick, id, interval)`,
   чтобы не было пиков. Топливо/износ — по смещению за интервал (как в оригинале), не каждый тик.
5. **Запись состояния**: в NBT/дата-трекер писать только при изменении (в Bedrock-скриптах свойства писались каждый тик — не повторять). gv_* не хранить постоянно, сохранять при выгрузке.
6. **Покрытие под машиной**: `SurfaceCache` — блок читать из мира только при смене блока (и раз в 20 тиков), `Surface.effect` без аллокаций.
7. **Регулятор** `Governor.update(mspt)` раз в тик (MSPT сервера). При перегрузке отключаются: частицы, лишняя рассылка, частота спидометра. Физику едущих НЕ урезать.
8. Горячий цикл без аллокаций: `Physics.horizontalVelocity(yaw, speed, lat, out)` с общим массивом; не создавать записи/списки на тик.
9. Что перемерить на ПК: реальный MSPT с 20–50 едущими машинами (spark), стоимость трекинга сущностей (entity tracking range машин держать небольшим, например 64–96), размер пакетов.
