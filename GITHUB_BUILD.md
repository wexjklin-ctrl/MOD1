# Сборка мода на GitHub (без ПК)

1. Зайдите на github.com, войдите в аккаунт (бесплатный подойдёт) -> **New repository**.
   Имя любое, например `rz_auto_mod`, **Public**, без README.
2. На странице репозитория нажмите **uploading an existing file**.
   Распакуйте этот архив на устройстве и перетащите внутрь **всё содержимое папки**,
   включая скрытую папку `.github`. Если браузер не даёт выбрать скрытые папки,
   создайте файл через **Add file -> Create new file**, назовите его
   `.github/workflows/build.yml` и вставьте туда текст из такого же файла архива.
3. Нажмите **Commit changes**. Сборка стартует сама: вкладка **Actions**.
4. Первая сборка идёт 5-15 минут. Результат: справа на главной странице репозитория
   раздел **Releases -> latest**. Там `build.log`, `selftest.log`, `api_dump.txt` и готовый `.jar`.
5. Пришлите мне ссылку на репозиторий, я прочитаю логи сам и скажу, что чинить.
