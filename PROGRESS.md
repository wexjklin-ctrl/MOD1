## Решения и разметка (сессия 17)
- Токен из чата использовался только для клона/пуша через `http.extraheader`, в репозиторий не пишется. API GitHub и Actions из песочницы закрыты, но `https://github.com/wexjklin-ctrl/MOD1/releases/download/latest/build.log` (и `api_dump.txt`) скачиваются curl: так смотреть результат сборки после пуша.
- Задники из `pasport.zip` (релиз addon) лежат в `assets/rz_auto/textures/gui/passport_{green,red,blue,beige}.png`, 1024x572. Красный/зелёный/синий = активная вкладка (язычок слит со страницей), бежевый = нет активной вкладки (документ не подписан, стол не для админа).
- Координаты в пикселях картинки (измерено по файлам): язычки зелёный (296,12,137x51), красный (440,12,212x51), синий (658,12,178x51); у бежевого другие (260..400, 407..652, 659..843). Тёмная панель под фото/печать: x 78..273, y 109..475. Рабочая область справа: x 300..915, y 86..525. Рамка: x 56..921.
- Админ = `ServerPlayer.permissions().hasPermission(Permissions.COMMANDS_ADMIN)` (проверено по api_dump).
- Модель данных: `PassportStore.Profile(name, date, country, seal)` на игрока (первый паспорт создаёт профиль: дата регистрации; страна/герб пустые, seal=-1, их вписывает админ в столе). Все паспорта игрока показывают данные профиля (клиент берёт их из `PassportInfoPayload.profile`), а не из NBT.
- Нарушение: `Violation(text, date, country, seal, issuer, seed)`; печать выбирается админом независимо от паспорта; `seed` даёт клиенту детерминированное смещение/наклон печати (рука, не программно).
