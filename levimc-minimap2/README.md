# Diorama for Bedrock (LeviMC client mod)

Клиентская миникарта и большая карта для Minecraft Bedrock (LeviLamina client), по мотивам Java-мода Diorama.
Только верхний мир. Радара нет.

Статус и план: см. [HANDOFF.md](HANDOFF.md). Сборка: GitHub Actions (`.github/workflows/levimc-build.yml`), артефакт `diorama-bedrock-*` в разделе Actions.
Установка: распаковать zip в папку модов LeviMC (рядом с другими модами, например MelonRind).
